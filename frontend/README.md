# Frontend

SPA en Angular 22 de la lista de tareas. El arranque del proyecto completo está en el [`README.md`](../README.md) de la raíz y las convenciones en `.cursor/rules/frontend-angular.mdc`.

```bash
npm install
npm start              # http://localhost:4200, con proxy de /api a http://127.0.0.1:8000
npm run lint
npm run format         # Prettier
npm run build          # dist/todo-frontend
```
